Studio notes

One studio. Five things built.

My approach is to start with a task someone can bring me, then make the steps visible enough to check together. That’s how a chart becomes an explanation, a search audit becomes a fix, and a payout becomes a trail someone can follow.

01 / VedaaChari

Make a chart easier to read.

I built a Vedic chart experience for personal reflection and a separate Sun & Moon companion for five Indian cities.

Under the hood
Next.js on Cloudflare Workers for the chart experience. The companion uses JavaScript and U.S. Naval Observatory data for local rise and set times.
My design choice
I separated measured sky events from chart interpretation, and paired Fraunces with Hind so the site has a distinct voice and room for Devanagari.
Private source repo ↗Live app ↗USNO data source ↗

02 / Universal SEO Agent Suite

Turn a finding into a fix.

I built workflows for search and AI discovery, plus a first-pass checker that inspects pasted HTML right in the browser.

Under the hood
The Python-led suite includes workflows for Codex, Claude Code and Antigravity. The browser checker uses JavaScript and offers a Google PageSpeed Insights report.
My design choice
I start with one public page, one documented obstacle and one proposed correction. If PageSpeed runs out of quota, the checker gives you the official report link.
SEO suite source ↗REA reference ↗

03 / FreeLLM Hub

Keep the prompt, change the model.

I built a trial workspace for model conversations and interactive artifacts, with provider and local gateway options.

Under the hood
A JavaScript app on GitHub Pages with streamed responses, OpenRouter support and local backends such as Ollama.
My design choice
I kept provider choice with the user so the same task can move between models. The trial makes provider limits and potential charges clear.
FreeLLM Hub source ↗

04 / REA Developer Ecosystem

Trace the tool call.

I put together architecture notes, reference MCP servers and deployment blueprints covering ReUI, Lighthouse, Context7 and Infimium.

Under the hood
TypeScript and the Model Context Protocol, with the upstream REA project as the reconstruction reference.
My design choice
I explain integrations as a route through a repository: find the entry point, follow the call and identify the permission it needs.
REA ecosystem source ↗Upstream REA ↗

05 / Omsetra

Give every payout a trail.

I built a reconciliation and collections workspace for Indian founders, small businesses and accountants, with three fictional demo journeys.

Under the hood
A TypeScript workspace with sample records that illustrate orders, refunds and payouts. The public demo has live payments disabled.
My design choice
I start with one discrepancy someone can recognize and follow through the records, so a pilot can focus on the step that costs them time.
Omsetra source ↗

The type came from VedaaChari.

I brought its Fraunces headlines and Hind body type across the studio. Fraunces gives each product a distinct headline. Hind keeps longer explanations and Devanagari easy to read.

The artwork has a job.
